# 속닥약속 조율이

## 기술 스택

### 프론트엔드

- React
- Vite (v6.3.5)
- JavaScript/JSX

### 개발 도구

- npm
- ESLint
- 기타 개발 의존성

## 시작하기

### 필수 조건

- Node.js (v18.0.0 이상 권장)
- npm

### 설치 및 실행

```bash
# 저장소 클론
git clone https://github.com/TeamiRoom/TeamiRoom-Frontend.git
cd TeamiRoom-Frontend

# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```
